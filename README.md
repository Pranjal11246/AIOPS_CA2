# Used Car Price Prediction API

A machine learning project that predicts used car prices using a trained regression model.

## Tech Stack

- Python
- Pandas
- Scikit-learn
- FastAPI
- Pytest
- Docker
- GitHub Actions

## Project Workflow

1. Train and evaluate a regression model using a Kaggle used-car dataset.
2. Save the fitted preprocessing and prediction pipeline as `model.joblib`.
3. Serve predictions through a FastAPI REST API.
4. Test the API using Pytest.
5. Containerize the application using Docker.
6. Run automated tests and a Docker build through GitHub Actions.
